# Something, Somewhere

Something, Somewhere is a small idea discovery website for people who want to build an app or website but are not sure what problem to start with. Enter a word or a handful of words, choose optional settings, and the site creates a short, grounded problem brief to explore.

The brief describes who is affected, what is happening, the pain point, and a challenge question. It leaves the solution open so the person using the generator can come up with their own product idea.

## Features

- Enter up to 12 words or short phrases. Add them with Enter or commas, or paste a comma- or line-separated list.
- Start quickly with example word sets.
- Choose an audience, problem space, where the problem happens, and challenge level. Each setting also has a broad default.
- Match words to curated scenarios and alternate scenario angles when they fit.
- Use broader word families and category-specific fallback scenarios for everyday inputs that do not directly match a catalog scenario.
- Label words as direct matches or as creative inspiration so the result does not pretend an unrelated word is relevant.
- Vary results and avoid recently shown briefs while other choices are available.
- Use the page on desktop or mobile, with keyboard support including Ctrl+Enter (or Command+Enter on Mac).

## Run it

Open `index.html` in a modern web browser. The generator runs in the browser and does not require a server, backend, API key, or external AI service. The page loads its preferred fonts from Google Fonts when an internet connection is available and includes local font fallbacks.

## Technology

- HTML for the page structure
- CSS for styling and responsive layouts
- Vanilla JavaScript for input handling, scenario matching, controls, and brief generation
- A local library of scenario data and word-family fallback templates

## Project scope

The generator creates starting points for problem discovery. Its results come from a finite, hand-written scenario library, so they are prompts for exploration rather than proof that a problem is widespread or a product idea will succeed.
